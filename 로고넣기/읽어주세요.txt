로고 넣는 방법
=====================================

1. 이 폴더에 로고 파일을 넣습니다.
   파일 이름은 바꾸지 않아도 됩니다.
   다만 파일 이름에 기관 이름이 들어 있어야 합니다.

     좋음  :  소상공인정책자금 로고.png
     좋음  :  소상공인365_CI.svg
     좋음  :  지식배움터.png
     안 됨 :  다운로드(1).png       ← 어느 기관인지 알 수 없습니다

2. 아래 명령을 한 번 실행합니다.

     npm run logo

3. 끝입니다. 어느 파일이 어디로 들어갔는지 화면에 나옵니다.


알아보는 기관 이름
-------------------------------------
지원사업 바로가기
  정책자금 / 365 / 지식배움터 / 소상공인24
  희망리턴 / K-Startup / 중소벤처기업부 / 소진공

함께하는 기관
  원주시 / 원주시의회 / 강원도 / 신용보증재단 / 상공회의소

협회 로고
  가로 / 세로 / 심볼


어떤 파일이 좋은가
-------------------------------------
  형식   SVG 가 제일 좋고, 없으면 PNG
  배경   투명 (흰 네모가 같이 붙어 있으면 어색합니다)
  모양   가로로 긴 로고
  크기   3MB 이하

  PNG 는 높이 100px 이상이면 충분합니다.


마지막 한 가지
-------------------------------------
파일을 넣은 뒤에는 홈페이지에 올려야 반영됩니다.

     git add -A
     git commit -m "기관 로고 추가"
     git push

이 부분이 어려우시면 그냥 "로고 넣었어" 라고 말씀해 주세요.
