# 임원 얼굴 사진 넣는 곳

여기에 **사람 이름으로** 사진 파일을 저장한 뒤 아래 명령을 실행하면
한 번에 조직도에 들어간다.

```
photos/
  박승환.jpg
  박규태.jpg
  이종현.jpg
```

```bash
node scripts/upload-org-photos.mjs photos/
```

- 파일 이름이 곧 조직도의 이름이다. 띄어쓰기 없이 이름만 적는다.
- 이미 사진이 있는 사람은 건너뛴다. 바꾸려면 `--force` 를 붙인다.
- 4:3 으로 자르고 가로 1600px 로 줄여서 올린다. 인물이라 위쪽(얼굴)을 남긴다.
- 사진 파일 자체는 저장소에 올리지 않는다 (.gitignore).
