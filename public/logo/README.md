# 로고 파일 넣는 곳

아래 이름 그대로 이 폴더에 저장하면 홈페이지에 자동으로 반영됩니다.
파일이 없으면 임시 마크가 대신 표시됩니다. (`src/lib/assets.ts` 가 파일 존재 여부를 확인합니다.)

| 파일명 | 쓰이는 곳 | 권장 형식 |
| --- | --- | --- |
| `wj-horizontal.svg` | 헤더 좌측 로고 (심볼 + 국문 + 영문 가로 조합) | SVG 우선, 없으면 `.png` |
| `wj-symbol.svg` | 파비콘, 푸터, 마무리 섹션의 심볼 단독 | SVG 우선, 없으면 `.png` |
| `wj-vertical.svg` | 협회소개 상단 등 세로 조합이 필요한 곳 | SVG 우선, 없으면 `.png` |
| `wonju-city.png` | 협회소개 '함께하는 기관'의 원주시 로고 | PNG/SVG |

## 주의

- **SVG를 권장합니다.** 화면 크기와 관계없이 선명하고 용량이 작습니다.
  일러스트레이터 원본이 있으면 `다른 이름으로 저장 → SVG` 로 내보내면 됩니다.
- PNG만 있는 경우 배경이 투명한 파일로 저장해 주세요.
  헤더는 흰 배경, 마무리 섹션은 짙은 배경이라 흰 사각형이 그대로 보입니다.
- 파일명을 바꾸지 마세요. 위 이름으로 찾습니다.
- `.svg` 와 `.png` 가 둘 다 있으면 `.svg` 를 씁니다.

## 원주시 로고

원주시 로고(CI)는 원주시의 자산입니다. 협회소개 '함께하는 기관' 안내 목적으로만
사용하고, 원주시 CI 사용 지침에 맞게 비율과 색을 임의로 바꾸지 않도록 합니다.
