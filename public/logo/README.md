# 로고 파일

이 폴더에 파일을 넣으면 홈페이지에 바로 반영된다. 없으면 임시 마크가 나온다.

| 파일 | 쓰이는 곳 | 모양 |
|---|---|---|
| `wj-horizontal.png` | 헤더(모든 화면 위쪽), 푸터 | **가로로 긴 조합** — 심볼 왼쪽 + 글자 오른쪽 |
| `wj-vertical.png` | 관리자 로그인 화면 | 세로 조합 — 심볼 위 + 글자 아래 |
| `wj-symbol.png` | 파비콘, 좁은 화면 | 심볼만 |
| `wonju-city.png` | 협회소개의 원주시 언급 부분 | 원주시 로고 |

- 확장자는 `.svg` → `.png` → `.jpg` 순으로 찾는다. **SVG 를 권장**한다.
- PNG 는 배경이 투명한 파일로 준비한다.
- 헤더는 높이 40px 로 그린다. 가로로 긴 로고는 세로 100px 이상이면 충분하다.

## 넣는 방법

개발 서버를 켠 뒤 `/dev/logo` 에서 끌어다 놓으면 이 폴더에 저장된다.
(이 화면은 개발 서버에서만 열린다.)

파일을 직접 넣어도 된다. 어느 쪽이든 **저장소에 커밋해서 올려야** 배포된 사이트에 반영된다.
